# 血糖管理软件 一期开发（本地版）

对应《03-一期开发任务计划》S0—S1 的本地部分：T01 工程骨架、T02 字段契约、T03—T06 日表填写与草稿、T10 回看（本地）。云端同步（T07—T09）、Excel 导出（T11）、PWA 与发布（T12—T14）未开始。

## 目录

- 仓库根：`code/`（pnpm 单仓库，TypeScript 严格模式）
- `packages/contracts`：记录 payload 判别联合、本地记录/草稿/同步状态类型
- `packages/domain`：F01—F09 字段模型、十进制校验（全角规范化、12位有效/4位小数、>0）、血压成对与反常确认、胰岛素剂量单位配对、日期规则；Vitest 25 个单测
- `apps/web`：React 18 + Vite，端口 5175
- `启动.command`：双击启动（自动开浏览器）

## 运行

```zsh
cd /Users/this_53/Desktop/老年人血糖管理软件/code
pnpm install
pnpm dev            # http://localhost:5175
pnpm test           # 领域单测
pnpm build          # 类型检查 + 产物构建
```

## 已实现（对应任务/验收）

- T01：pnpm workspace、依赖锁定（lockfile）、TS strict、.gitignore、git 提交。CloudBase PG/认证/备份验证未做（不采购、不承诺）。
- T02/T03：手机分组日表（血糖默认展开、其余组已填摘要）、电脑日表（项目/时点/已记录内容/操作）、日期切换与日期选择、补记横幅「正在补记：YYYY-MM-DD」与回今天、未来日期禁选。
- T04/T05：血糖 7 时点+临时测量（多条）、血压成对（收缩压<舒张压要求确认）、体重早晚、三餐文本、饮水累计（允许 0）、运动（可选时长）、胰岛素（原文必填、剂量须带单位）、一日纪要；数值十进制字符串校验、文本 4000 上限、错误定位字段不截断输入。
- T06：IndexedDB 原子写（records+drafts 分离）、草稿自动保存并标「草稿，仅此设备」、刷新恢复、保存失败不显示成功、删除确认+30 天软删除（日明细可恢复）、Escape 有修改先询问。
- T10（本地）：日明细（版本/时间/删除状态）、月表按实际日历天数（2月/闰年支持）点日进入日表、血糖趋势默认近 7 天空腹、同单位同时间点分组、缺失不补零不连线、明细表。
- 设置：18/22/26 字号（默认 22，切换不丢内容、本机记忆）、单位配置（标「待确认」，改默认不影响历史）、虚构示例数据载入/清空。
